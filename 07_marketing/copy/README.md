# Copy Library

Reusable Hebrew copy components for Road Protect. Pull from here when building landing pages, ads, emails, and bot scenarios so the brand stays consistent.

Organize by surface:
- `headlines/` — hero headlines and section headers
- `value-props/` — the canonical phrasings of the value props
- `ctas/` — call-to-action variants
- `social-proof/` — partner / stat / testimonial copy
- `emails/` — email template library
- `whatsapp/` — non-bot WhatsApp templates (e.g. broadcast announcements)

*(folders to be populated as work happens — start with the relevant surface for whatever campaign is live)*

## The 3 canonical taglines (use these as anchors)

1. **השקט שלך מתחיל כאן** — emotional, broad. Best for hero / brand-level surfaces.
2. **סורקים עבורך קנסות אבודים מול כלל הרשויות** — functional, specific. Best for explanation-mode pages.
3. **ההגנה שלך בדרכים** — possessive, ownership. Works in headers and email subject lines.

## The 3 canonical urgency hooks

1. **ריבית פיגורים אוטומטית של 50%** — concrete cost.
2. **כפל קנס מהדוח הרביעי בתוך 3 שנים** — escalation cost.
3. **נקודות שיכולות לסכן את הרישיון** — license risk.

Pick one per piece of copy. Don't pile all three together — it reads as fear-mongering.

## Brand promise (single sentence)

> Road Protect מאתרת עבורך כל קנס שמופיע על השם שלך — לפני הדואר, לפני הפיגור, לפני הנקודות.
