# Brief Pack — Fear-Factor (Cameras) + "MAX" Waitlist Block

**Purpose:** everything a copywriter (or Gemini) needs to write the Hebrew copy + a short copy-spec for the landing-page block that combines the **new camera-enforcement reality** with our **future product "MAX"** and its **waiting-list form**.

This pack is **self-contained on purpose** — Gemini has none of our workspace context, so all the facts, sources, product details, brand voice, and legal limits are inside these files.

## How to use with Gemini (or any writer)

1. Paste files **01–04** into Gemini as context (the data, the product, the voice, the red lines).
2. Paste file **05** as the actual instruction (the prompt).
3. Gemini returns: (a) the Hebrew copy for the block, (b) a short copy-spec.
