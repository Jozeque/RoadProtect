# Marketing Campaigns

Each campaign gets its own folder: `YYYY-Q#_<short-name>/`.

Inside each folder:
- `BRIEF.md` — the campaign brief (goal, audience, message, channels, budget, success metric)
- `copy/` — all copy variants (subject lines, body, CTAs, A/B variants)
- `creative/` — image / video / mockup assets
- `results.md` — post-campaign retrospective and numbers
